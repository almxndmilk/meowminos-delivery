## Prerequisites

Make sure you have the following installed before building or running the game:

- **Java JDK 11** or newer — [Download](https://adoptium.net/)
- **Apache Maven 3.6+** — [Download](https://maven.apache.org/download.cgi)

To verify your installations, run:

```bash
java --version
mvn --version
```

---

## Building the Game

Clone the repository and navigate to the project folder, then run:

```bash
mvn package
```

This compiles the source code and packages everything into a runnable JAR file inside the `target/` folder.

---

## Running the Game

```bash
mvn exec:exec
```

> **Note:** Do **not** use `mvn exec:java` — LibGDX requires a fresh JVM with native libraries loaded, which only `exec:exec` supports. The correct command is automatically chosen for your operating system (macOS or Windows/Linux).

---

## Running Tests

```bash
mvn test
```

Test results will be printed in the terminal. Detailed reports are saved to:

```
target/surefire-reports/
```

---

## Generating Javadoc

```bash
mvn javadoc:javadoc
```

The generated documentation will be saved to the `javadoc/` folder. Open `javadoc/index.html` in a browser or extension to view it.

## Common Issues

**Game won't launch on Windows**
Make sure you are using `mvn exec:exec` and not `mvn exec:java`. The `-XstartOnFirstThread` flag used by the macOS profile will cause crashes on Windows — this is handled automatically by Maven profiles.

**`java` or `mvn` not found**
Make sure Java and Maven are installed and added to your system's `PATH` environment variable.

**Build errors about Java version**
This project requires Java 11. Run `java -version` to confirm. If you have multiple JDK versions installed, set `JAVA_HOME` to point to JDK 11.
